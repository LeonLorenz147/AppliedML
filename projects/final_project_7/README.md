# Project 7: Forecasting Electricity Load with Time-Based Fourier Features

## Overview
This project predicts household electricity consumption using calendar-time features
encoded as Fourier (sine/cosine) transformations. The main experiments study how well electricity demand 
can be predicted from periodic time information such as hour of day, day of week, and day of year. 
We compare linear models, OLS and Ridge regression, with a shallow neural network.

As an additional experiment, we also test autoregressive lag features based on past consumption values.
This allows to evaluate whether recent household consumption provides predictive information beyond calender time periodicity.

## Dataset
UCI Individual Household Electric Power Consumption (2006–2010).
Minute-level electricity readings from a single household, resampled to hourly.

Download from:
https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption

## Project Structure
- `notebooks/Linear_Regression.ipynb`: preprocessing, Fourier feature construction, OLS/Ridge regression, K experiments, prediction and residual plots.
- `notebooks/Shallow_NN.ipynb`: shallow MLP implementation and comparison against Ridge regression.
- `notebooks/autoregressive.ipynb`: autoregressive experiment using lagged consumption features and comparison against Fourier-only Ridge regression.
- `notebooks/further_analysis.ipynb`: correlation analysis of electrical variables and sub-metering prediction experiments.
- `figures/`: saved plots generated by the notebooks.

## Notebooks / Models
**1. Linear Regression**
- Builds Fourier features from hour, day of week, day of year
- Trains OLS and Ridge regression
- Experiments with K = 1, 3, 5, 10 frequency components
- Produces plots: basis functions, predictions vs actual, residuals, RMSE vs K

**2. Shallow Neural Network**
- Uses same types of Fourier features as input
- Trains a shallow MLP (input → 64 → 32 → 1) with ReLU activations
- Produces plots: training loss curve, predictions vs actual, residuals

**3. Autoregressive Model**
- Testes if past electrical consumption improves forecasting performance 
- Uses lagged target values such as previous hour, the same hour on the previous day 
and the same hour in previous week
- Compares autorgressive-only features with combined Fourier + autoregressive feature 

**4. Further Analysis**
- Computes correlations between global electrical variables and sub-metering variables
- Trains Fourier-feature models for the three sub-metering targets

## Preprocessing
The original minute-level measurements are parsed into timestamps using the `Date` and `Time` columns. 
The target variable `Global_active_power` is resampled from minute-level to hourly mean consumption. 
The train/test split is chronological, using the first 80% of the time series for training and the remaining 20% for testing.

## Fourier Features
We encode periodic time variables using sine and cosine transformations. 
The main features are based on hour of day, day of week, and day of year. 
This allows linear models to represent periodic daily, weekly, and seasonal consumption patterns.

## Results Summary

### Linear Models (Fourier features for hour, weekday, and day of year)
| Model | RMSE   | MAE    |
|-------|--------|--------|
| OLS   | 0.6396 | 0.4902 |
| Ridge | 0.6396 | 0.4902 |

OLS and Ridge perform almost identically in the main Fourier-feature setup, 
suggesting that regularization has little effect for this feature representation.
In the hour-only Fourier experiment, increasing K from 1 to 10 
reduces the test RMSE from 0.727 to 0.670, with smaller gains after K=5.

### Neural Network (500 epochs, lr=0.001)
| Model          | RMSE   | MAE    |
|----------------|--------|--------|
| Neural Network | 0.9056 | 0.7059 |

### Model Comparison
| Model          | RMSE   | MAE    |
|----------------|--------|--------|
| OLS            | 0.6396 | 0.4902 |
| Ridge          | 0.6396 | 0.4902 |
| Neural Network | 0.9056 | 0.7059 |

OLS and Ridge regression outperform the shallow neural network on this task.
This is plausible because Fourier features already encode much of the periodic structure
linearly, leaving little advantage for nonlinear modeling. The neural
network may improve with more epochs or hyperparameter tuning.
All RMSE and MAE values in the linear-model, neural-network and model-comparison tables are measured in kW 
because the target variable is hourly mean `Global_active_power`.

## Autoregressive Model
The autoregressive experiment shows that lagged consumption contains important predictive information beyond calendar-time periodicity.

| Model              |   RMSE |    MAE |
| ------------------ | ------ | ------ |
| Fourier only Ridge | 0.6396 | 0.4898 |
| AR only Ridge      | 0.5235 | 0.3727 |
| Fourier + AR Ridge | 0.5049 | 0.3635 |

Compared with the Fourier-only Ridge model, the combined Fourier + AR model reduces RMSE from 0.6396 to 0.5049 and MAE from 0.4898 to 0.3635. 
This corresponds to an error reduction of about 21,1% for RMSE and 25,8% for MAE. 
This shows that recent household consumption is useful for short-term load forecasting.

## Key Findings
- Electricity consumption follows strong daily and weekly cycles
- Fourier features effectively encode these periodic patterns
- In the hour-only Fourier experiment, most gains occur by K=5, while K=10 gives only a small additional improvement
- Linear models are well-suited for this periodic regression task
- The neural network captures the daily rhythm but misses sharp spikes
  caused by individual appliance usage, which calender time features cannot predict
- Autoregressive lag features substantially improve performance compared with the Fourier-only Ridge model


## Limitations
The main Fourier-feature models only use calendar-time features and therefore capture average periodic structure rather than sudden appliance-level spikes. 
Adding autoregressive lag features improves performance, but the model still cannot fully predict irregular appliance-driven spikes. The approach also depends on past consumption values being available at prediction time and does not include external factors such as weather, holidays, occupancy, or appliance-level information.


## Reproducibility
All experiments can be run end-to-end from their corresponding notebook.
Random seeds are not required as linear models are deterministic.
For the neural network, results may vary slightly between runs due to
random weight initialization.
